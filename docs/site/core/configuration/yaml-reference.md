# Legacy YAML input для миграции

Core runtime больше не читает `core.yaml`. Старый формат остаётся входом только
для внешней команды [liapoldus core migrate](migration). Не создавайте новые YAML-файлы и
не запускайте Core с удалённым `--config`.

Команда миграции проверяет старый документ по сохранённой схеме и переводит
ссылки на файлы относительно исходного YAML. Содержимое secret-файлов она не
читает. Подробности текущих возможностей и ограничений описаны в
[руководстве по миграции](migration).
